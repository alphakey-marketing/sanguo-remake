# UX — 手機橫屏線框 (Step 3.2)

畫面 1024×640 橫屏。原則：**一手（右手拇指）可達**，重要掣放左右下角，中間留畀世界。

## 主畫面（世界）
```
+--------------------------------------------------------------+
| [HUD: 名 Lv 善惡階]                              [背包 B]     |
| HP/MP/SP/EXP 條                                              |
|                                                              |
|                     世界（點地行路/點怪）                     |
|                                                              |
| 聊天/戰報 (最多 6 行)                                         |
|                                            +------------+    |
|                                            | 戰鬥/行走  |    |
|                                            |   切換掣   |    |
|                                            +------------+    |
+--------------------------------------------------------------+
```

## 畫面清單
| 畫面 | 狀態 | 備註 |
|---|---|---|
| 世界 + HUD | ✅ | 善惡顯示七階名 + 數值 |
| 背包 | ✅ debug | 右上；之後改觸控格 |
| 客棧 / 武器店 | ✅ debug | 走近出面板；之後改觸控按鈕 |
| 對話（Step 6.5） | 未做 | 頭像+對話框+預設選項+自由輸入 |
| 設定（API key） | 未做 | Step 6.3 |

## 操作對應
| 意圖 | 桌面 | 手機 |
|---|---|---|
| 行路 | 左鍵點地 | 點地 |
| 切戰鬥/行走 | 右鍵 | 右下切換掣（紅=戰鬥，藍=行走） |
| 攻擊（自動追擊） | 戰鬥模式左鍵點怪 | 戰鬥模式點怪 |
| 休息 | R / 點客棧面板 | 點客棧面板 |
| 買/賣 | 1-3 / X | 點面板（待做） |

觸控由 Godot 預設 `emulate_mouse_from_touch` 轉成左鍵，故同一套輸入碼通用；右鍵功能由切換掣取代。
