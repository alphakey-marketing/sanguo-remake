## 1. 核心循環【原】
行走(左鍵點地) / 戰鬥(右鍵切戰鬥游標 → 左鍵點敵，衝過去) / 溝通(頻道)
賺錢: 打怪撿錢撿寶 → 賣；工作技能取物資 → 賣或做進階品；修理服務
**戰鬥 = 即時制**（非回合制）。回合/佈陣只係國戰。

## 2. 角色
- 名字≤8 字不可改、稱號可改、生日、臉譜(8 部位自訂)、**潛質心理測驗 → 理念**(義理/霸權/權謀/隱遁/治國，決定可登用武將)
- 六職(男: 義士/辯士/道士；女: 仕女/巫女/美女)。50 級二轉、100 級三轉 (義士→武士→猛將 …)
- 六屬性: 武力(攻擊威力) 敏捷(攻速) 智力(智力系術) 靈力(靈力系術) 政治(內政效果) 魅力(買賣價)
- 三值: HP / MP(術法) / SP 體力(工作技能、職業特技、絕招)
- 屬性修練: 練兵場(2 人組隊互搏，扣 HP+SP，+10 歷練，升級時武/智/敏/靈提升)、私塾(政治+1，扣 SP/MP)、寺廟(魅力+1)
- 專長 ≤4 級: 內政(開墾/修築/探礦/招徠/工藝/飼育，各職基本專長)、義勇軍(交易/訓練/警戒/偵查/統御/補給)、其他(救災/天文/地理)
- 5 級脫離新手 (新手介面 4 鍵，之後 6 鍵)

## 3. 戰鬥【原】
- 三種: 物理(近/中/遠，武器)、術法(耗 MP，需吟唱，遠距)、絕招(耗 MP+SP，大範圍，靠事件習得，隨武器)
- 防禦: 術防/物防(看防具)
- 屬性相剋: 地剋水、水剋火、火剋風、風剋地；寶石: 風/地/水/火 +10%~+100%(各 10 階)，另有輔助/特殊寶石
- 術書: 地/水/火/風之術(小10/中25/大40/特55 級)、葉/針(無屬性，5~45 級)；限職(辯/巫/道，特級=仙君)；裝備對應屬性石
- 武器 6 組(見職業表)，來源: 武器店/任務/打怪
- 傷害公式: **無** →【自訂】

## 4. 善惡 / PK / 死亡【原，有數字】
- 善惡值 -30000~+30000；PK 值 1 = -1000；七階: 大英雄(≥16001) 善人(8001~16000) 好人(1001~8000) 中立(±1000) 罪犯(-1001~-8000) 惡人(-8001~-16000) 殺人魔(≤-16001)
- 殺善玩家(自身為正/善): 直接扣成 -1000；惡人殺善: 累積 -1000；善/中立殺紅人 +300；紅殺紅 +300；反擊主動攻擊者成功 +100；殺善 NPC 扣、殺惡 NPC 加
- 紅紫人攻擊善良玩家 → 黃人 10 分鐘(不能傳送/召喚，下線角色留 1 分鐘)
- 天譴: 練功山洞殺善良玩家 → 即死回客棧，不可還魂丹/超渡
- 死亡掉裝備: ≥-1000 掉 1 件機率(善低惡高)，-1001~-8000 掉≤3 件，-8001~-16000 掉≤6，≤-16001 掉≤7
- 死亡掉經驗: 善惡≥-1000 → 該等級所需經驗 10%；<-1000 → 20%
- 幸運符抵掉落、護身符經驗減半；惡值高 → NPC 買物更貴

## 5. 工作技能 / 經濟【原】
- 初階 6 項(10 級可做): 農耕/狩獵/伐木/釣魚/採藥/採礦，需工具(有耐久)，工作區在城外，經城門「工作指標」進入
- 50 級 → 進階: 農耕/捕魚/打獵→廚藝(菜餚回 HP)；伐木→木匠(箭、修項鍊戒指)；採礦→冶鐵(修武器)、修繕(修防具)；採藥→煉丹(補藥回 MP)。進階在室內
- 天地商行: 200 兩/天，子時扣款，代買賣/存材料/買賣工具/休息
- 大宗師合成術: 初階 100 級 + 進階 20 級解鎖，御賜工具，新材料(黃金稻穗、飛天龍魚…)，合成寶石
- 物資用途: 賣錢 / 進貢城池換名聲 / 捐義勇軍換功績 / 進階材料
- 聊天頻道扣飲水度(公用最多)

## 6. 世界 / 練功區【原】
- 怪物大全按等級分區: 荊州/豫州/并州司隸 1~10、袞州徐州 10~20、大地圖夜間 25~35；汝南洞 5~20、濮陽洞 14~40、晉陽洞 25~45、譙/桂陽 46~50、長沙/宛城 51~60、鄴城/廬江 61~70、襄平 71~80、建業 81~90；桃花渡 75~80、黑山寨 90~95、安定戰場 95~100、雪山/潼關/西洱河/瀘水/異族禁地/七彩奪寶陣 100
- 新手城: 許昌/洛陽/襄陽；其餘城池(小沛/宛城/陳留/新野…)；城內有練兵場/私塾/寺廟/客棧/馬廄/官宅/錢莊
- 時間: 十二時辰+刻(子時2刻…)；季節(春夏秋冬)；天災 7 種(蝗蟲/瘟疫/旱/颶風/洪水/暴風雪/地震)，大中小規模，看城池防災度/救災度

## 7. 任務【原】
新手 / 一般 / 官令(有頭銜者，每日 1 次，扣行動力 10) / 團體 / 歷史 / 絕招(一~六招，每職一條，例: 義士「萬里鷹翔」=20 級+汝南山洞十層收 20 霸盜令 → 飛鷹寶戟) / 特技絕招 / 戰役 / 專長 / 特殊場景(桃花渡/黑山寨/安定戰場/通天關/雪山/七彩奪寶陣/異族禁地)；三轉=七彩項鍊(打 7 個孟獲換真晶)

## 8. 座騎 / 戰騎【原】
- 座騎: 幼馬→成馬(飼育，教育決定屬性)→配鞍騎乘；6 種馬(學習/奔跑/體力/平均/爆發/忍耐)；最多 5 匹；可繁衍
- 戰騎(寵物戰鬥): 獸力→攻擊、獸體→HP/防、獸靈→術攻/MP、獸敏→物迴/攻速；8 種(巨角牛/疾風狼/殘影豹/九尾狐/焰牙虎/霸王熊/長牙象/嗜血獅)，屬性總和皆 19；有配點、特技、PK

## 9. 社會 / 後期【原】
- 名聲→頭銜(60 階，如 50=征東將軍 45000 名聲；行動力上限 100+2×階)；頭銜每月競爭有名額
- 義勇軍: 頭銜南中郎將(名聲 3000)、25 人擁護(各 Lv5+名聲 100)、20 萬經費、非新手城定居；品階一~八；營地建設/設施/內政/民心
- 帶兵量 = 7000 + 品階(8000~1000) + 頭銜(1~20 階每階 +200，21~40 +250，41~50 +400)，51+ 階固定 28000
- 登用: 理念相合(五角關係) + 個人屬性 → 武將(600+ 出仕武將)，最多 3 種理念，御賜金牌無視
- 結婚 / 國戰 / 歷史戰役(討伐程遠志、三公、長阪坡、赤壁、潼關…) → 後期，暫不做

## 給 remake 的分層
- L1 循環: 建角(職業+屬性+理念測驗)、地圖、即時戰鬥(近戰+簡單術法)、怪物+掉落、NPC 商店、升級、死亡處分、善惡值
- L2 生產: 6 初階技能 + 4 進階 + 工具耐久 + 天地商行
- L3 成長: 二轉(50)、專長、座騎/戰騎、寶石屬性
- L4 社會: 名聲/頭銜/義勇軍/登用/任務鏈/天災
- L5: 國戰
