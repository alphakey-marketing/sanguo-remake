# 熱鍵指令
# http://syfree.chinesegamer.net/sy1_2_10.asp

【三國演義Online】免費經典遊戲任你玩
 遊戲熱鍵
 熱鍵作用說明
 ESC
 關閉最後一個開啟的主視窗介面
 DELETE
 清除對話視窗上的所有文字
 TAB
 呼叫主操控介面
 PAGE UP 
 聊天介面訊息往前捲頁
 PAGE DOWN
 聊天介面訊息往後捲頁
 SHIFT+PAGE UP
 對話框輸入上一句話
 SHIFT
 +PAGE DOWN
 對話框輸入下一句話
 ALT+F1
 道具指令快捷列往前捲頁
 ALT +F2
 道具指令快捷列往後捲頁
 F１
 觸發物品指令快捷列左邊第一行（或第二行）
 算來第一格
 F２
 觸發物品指令快捷列左邊第一行（或第二行）
 算來第二格
 F３
 觸發物品指令快捷列左邊第一行（或第二行）
 算來第三格
 F４
 觸發物品指令快捷列左邊第一行（或第二行）
 算來第四格
 F５
 觸發物品指令快捷列左邊第一行（或第二行）
 算來第五格
 F６
 觸發物品指令快捷列第一行與第二行的準備狀態切換
 ALT+A
 使用第一種裝備武器
 ALT+S
 使用第二種裝備武器
 ALT+D
 使用第三種裝備武器
 ALT+F
 開啟關閉術法快捷列
 ALT+L
 固定/解開，可移動介面
 ALT+M
 開啟關閉即時動態小地圖
 ALT+P
 將現在畫面存成BMP檔案，存放在硬碟的SY ONLINE檔案夾中
 ALT+Q
 離開遊戲
