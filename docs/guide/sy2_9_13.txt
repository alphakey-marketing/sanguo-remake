# 作戰相關規則
# http://syfree.chinesegamer.net/sy2_9_13.asp

【三國演義Online】免費經典遊戲任你玩
 　★ 宣戰流程：
 1.
 君主於宣戰時間至義勇軍營地選擇「宣戰」指令。
 2.
 待畫面秀出後，先點選出征點再點選攻擊點，按下確定後即完成宣戰動作。
 3.
 當義勇軍起義時，頭目點選的出征點和攻擊點為同一座城池。
 4.
 君主、頭目在反白區域上按左鍵時會顯示該場戰役的情報，按右鍵會顯示放棄進攻的視窗。
 　★ 出兵流程：
 　　當該勢力被排進當週場次表時，君主(太守)、頭目可於開戰前一小時由義勇軍介面選擇”出兵”進行編組並儲存(儲存後不能再修改)，每場戰役進攻方及防守方能出征人數各為30人。 
 1.
 君主(頭目)的使用權─ 
 【針對自己勢力下所有的進攻、防守、支援場次進行編組】、【所有城池支援的使用權】、【人員安排】、【編組名單儲存】。
 (註：人員需定居在義軍營地所在城池，方可接受編組) 
 2.
 太守的使用權 ─
 【針對自己駐守城池所有的進攻、防守、支援場次進行編組】、【駐守城池支援的使用權】、【人員安排】、【編組名單儲存】。
 (註：人員需定居在義軍營地所在城池，方可接受編組) 
 3.
 一般玩家的使用權─
 【觀看所有場次的場次名單】。
 (註：此使用權前提必須要加入義勇軍，並且可以觀看所屬勢力的頭目編組儲存後名單) 
 【練習編組名單】。
 (註：此使用權前提必須要所屬勢力義勇軍的頭目開放使用權限，方可練習) 
 　★ 進攻流程：
 1.
 當玩家的勢力被排進場次表時，該勢力所有玩家上線後畫面會秀出一次提示視窗。 
 2.
 攻方君主、頭目可於【宣戰】的場次取消進攻。 
 3.
 開戰當日前一小時進行出兵編組並儲存名單。
 4.
 開戰時間在義勇軍營地的玩家如在出兵名單內，可選擇【出兵】選項內的出兵進入戰場。 
 　★ 防守流程： 
 1.
 當玩家的勢力被排進場次表時，該勢力所有玩家上線後畫面會秀出一次提示視窗。 
 2.
 開戰當日前一小時提出求援或進行出兵編組並儲存名單。 
 3.
 開戰時間在義勇軍營地的玩家如在出兵名單內，可選擇【出兵】選項內的出兵進入戰場。
