# 何為國戰
# http://syfree.chinesegamer.net/sy2_9_10.asp

【三國演義Online】免費經典遊戲任你玩

 　　三國演義裡最令人血脈奮張的莫過於玩家與玩家之間的鬥智與鬥力─國戰系統，何謂國戰？單就字面上的解釋，指的是國與國之間的戰鬥；而在此所謂「國」的定義，指的是擁有固定疆域領土主權及人民的集合團體。在三國演義Online中，最小的單位是個人，最小的團體是隊伍，此二者均未達到形成國家的基本要求；至於再上一級的就是所謂的義勇軍，則是國家團體的初步實現，有一根據地、有管理機制亦即主權、同時有一定數量的成員；而以義勇軍的身分攻下城池之後，便成為軍團，原本的義軍頭目變為太守，其實就是割據一方的地方勢力；而在各勢力攻城掠地，擴張領土，彼此併吞之後，終於變成在單一勢力之下統治數座城池的狀態，這時國家的機能便已完全具備，太守據地稱王，成為君主，綜合以上述各種勢力與勢力間的競爭、談判、馳援、攻防，就是三國演義Online「國戰系統」的規劃方向。

# 國戰規則
# http://syfree.chinesegamer.net/sy2_9_12.asp

【三國演義Online】免費經典遊戲任你玩

 　★ 宣戰須知：

 1.
 頭目提出宣戰要求時，每排定一場次需消耗50行動力。

 2.
 在野勢力義勇軍只能對其所在的定居地城池宣戰，意謂佔有城池之一方必須對抗其他勢力的叫戰防守自己領土。

 3.
 擁有城池的勢力義勇軍只能對其與所在城池相鄰近的城池宣戰，但是無法對所屬城池的在野勢力義勇軍宣戰。

 4.
 特殊狀況說明：

 當A勢力義勇軍於甲城起義，並戰勝擁有甲城的B勢力義勇軍，而若B勢力義勇軍原預定進攻乙城的場次則會被取消，因為B勢力並非城池擁有者，因此無法對乙城池進行宣戰的動作。

 5.

 當甲城池與丙城池的勢力皆有排定場次準備進攻乙城池，若甲城池先攻，並成功的攻下乙城池，雖然城主易主，但是丙城池對乙城池的進攻場次乃然不變，甲城池乃然必需面對丙城池的進攻。

 　★ 宣戰日期：

 1.
 正規宣戰時間：
 為星期日1800~2000，玩家需在這段時間內向系統提出宣戰要求，當時間一到玩家即不可再提出宣戰，此時系統會比對所有的宣戰勢力排定下一週的場次。 

 2.
 取消宣戰時間：
 為現實時間週一至週六1800~1900，週日取消的時間為2030~2130，玩家可在這段時間取消隔天之後的場次，但一週內不得再由此城池提出宣戰要求。 

 　★ 宣戰時間：

 1.
 國戰時間為週一至週日，一小時有一場，一週總共有50場次。

 2.
 當玩家宣戰後，如與敵對勢力和談可於1800~1900在宣戰介面放棄對該勢力的進攻，但只限於放棄隔天之後的場次。

 　　當該勢力被排進當週場次表時，君主(太守)、頭目可於開戰前一小時由義勇軍介面選擇”出兵”進行編組並儲存(儲存後不能再修改)，每場戰役進攻方及防守方能出征人數各為30人。

 君主(頭目)的使用權─

 (註：人員需定居在義軍營地所在城池，方可接受編組)

 【針對自己駐守城池所有的進攻、防守、支援場次進行編組】、【駐守城池支援的使用權】、【人員安排】、【編組名單儲存】。
 (註：人員需定居在義軍營地所在城池，方可接受編組)

 一般玩家的使用權─
 【觀看所有場次的場次名單】。

 　★ 進攻流程：

 3.
 開戰當日前一小時進行出兵編組並儲存名單。

 4.
 開戰時間在義勇軍營地的玩家如在出兵名單內，可選擇【出兵】選項內的出兵進入戰場。

 開戰時間在義勇軍營地的玩家如在出兵名單內，可選擇【出兵】選項內的出兵進入戰場。
