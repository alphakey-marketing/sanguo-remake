# 天地商行
# http://syfree.chinesegamer.net/sy2_2_4.asp

【三國演義Online】免費經典遊戲任你玩

 　　天地商行對於玩家使用初階技能，是個超便利的機能。使用天地商行，玩家一切的的生活所需絕對不虞匱乏喔！

 　★ 使用方法：

 　　天地商行其實是個幫玩家處理練技能時一些例行工作的腳伕功能，幫玩家跑腿買賣物品、跑腿存物品、連休息都能代勞，不能不說服務周到！進入大家熟悉的工作區之後，路標旁多了一個人，原來他就是天地商行的駐城掌櫃（另一邊則是駐城雇員），他告訴我們天地商行即日起24小時營業，希望大家多多光臨。

 基本上天地商行的使用步驟有四：

 1.
 設定所需服務：
 經由一些設定，將可達到玩家所要的效果。

 2.
 繳交僱用費用：
 一天僱用費用為二百兩，且在每日子時準時從玩家的戶頭中扣款。

 3.
 選擇自動續約：
 只要勾選自動續約，他們可是一直為您工作下去的喔。

 4.
 選擇自動連線：
 只要勾選自動連線，遇到短時間的維護工作時，系統將幫玩家自動連上線，玩家可以高枕無憂啦！！

 5.

 開始工作：
 還不快拿起你的工具，努力賺錢吧！

 　★ 服務功能介紹：

 1.
 工作區小屋休息：
 再也不用辛辛苦苦跑到客棧，補充體力又省時間，不過休息的錢還是要算的喔！ 

 2.
 存材料

 a.
 基本機制：
 共可在六項初階技能之中做設定，勾選想要存入錢莊的物資，在玩家的負重滿了之後，腳伕便會將所勾選的物資送去錢莊存入。

 b.
 手續費：
 費用錢莊手續費的作法比照一般存物品至錢莊的方式處理，當然比起自已親自送去錢莊存來說，是比較不會那麼辛苦就是了。

 c.
 錢莊存滿後的處理：
 不過當錢莊的物品存量限額滿了之後，腳伕就不再幫玩家存入，而是直接被賣到市集上，此外若是沒有勾選要存的材料，這些材料也會被賣到市集上去。

 3.
 買工具：
 若勾選此項而未選賣工具，當玩家 的工具耐久度變成0的時候，腳伕將會自動幫您把這把丟棄，買一把新的使用，您可不用親自跑一趟了。

 4.
 賣工具：
 若勾選此項，所使用的工具會在耐久度剩2的時候自動賣出，但若未勾選買工具的話，您的手中就沒工具可用了喔，這點請務必注意。
