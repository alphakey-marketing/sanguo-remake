# 購買道具流程
# http://syfree.chinesegamer.net/sy4_3.asp

【三國演義Online】免費經典遊戲任你玩
 　　「三國演義ＯＮＬＩＮＥ」免費版終於開放了，還不知道如何使用所儲值的點數購買虛擬寶物的玩家請注意，接下來就特地為大家進行「不複雜、超簡單的虛寶購買！」教學流程喔！
 　★ＳＴＥＰ１　確認是否儲點
 玩家在進入遊戲之後，如果想要購買虛寶，玩家必須確認自己的帳號內是否儲有點數，請玩家從「系／系統／餘數」進入，經過系統查詢之後，玩家帳號內的剩餘點數就會出現在對話視窗中喔！！
 　★ ＳＴＥＰ２　進入店舖介面
 玩家確認完點數無誤之後，接下來就要進入店舖介面，在玩家初始的快捷列中可以看到一個「店鋪」ICON，或是玩家可由「系／系統／店鋪」進入。
 　★ ＳＴＥＰ３　設定初始密碼
 第一次進入店舖介面的玩家必須先設定啟動密碼，並確認是否以後進入店舖介面時，都要啟動密碼認證。
 　★ ＳＴＥＰ４　店鋪介面選項
 設定完密碼之後，玩家就能進入店舖功能的選項介面，共有４個功能，分別是「進入店舖購物」、「是否使用密碼」、「是否修改密碼」及「是否修改姓名」，玩家可依自己的需求選擇。
 　★ＳＴＥＰ５　 商品種類選擇
 一旦選擇了「進入店舖購物」選項，玩家首先即可看到商品種類的選項，目前共分為六大項「武器類」、「防具類」、「實用類」、「丹藥類」、「武將類」及「技能類」，選定之後即可進入購買介面喔！
 　★ ＳＴＥＰ６　進入購買流程
 如選擇的虛寶種類是「武器類」，玩家即會進入武器類購買介面，左側部分為玩家已購買的商品，右邊則是目前可供販賣的商品，玩家一次可以選擇１０種商品購買，１種商品一次只能購買１個。
 　★ＳＴＥＰ７　 進行結賬作業
 玩家選定所有想買的商品之後，按介面下的「買」，即會進入結帳作業，系統會列出所有購買的商品，並總計所需的點數，玩家確認之後，按「○」即可進行購買。
 　★ 
 ＳＴＥＰ８　使用虛寶囉！！
 買完之後，快到裝備欄中檢查一下商品是否已經到貨囉！穿上戴上買好的虛寶，快快樂樂地進行你的三國冒險吧∼∼！！
