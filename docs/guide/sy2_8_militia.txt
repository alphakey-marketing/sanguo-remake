# 經營之路
# http://syfree.chinesegamer.net/sy2_8_1.asp

【三國演義Online】免費經典遊戲任你玩

 　　三國演義online的經營之路，是以任務導向為主的系統，不論你是名不見經傳的隱士，還是能獨當一面的義勇軍頭目，甚至是睥睨中原的一國之君，在任何階段都有著各種不同類型的任務考驗，小從以個人修練為主，大到需整個團隊共同合作。除了平時修身外，還有建設、經營、內政、謀略和外交等等，重重考驗陪著你一起成長。

 　★ 在野時的抉擇

 　　在野時，並不會受到任何的拘束，你可以依照自己的興趣去從事相關的工作或修練。比方說提升個人戰鬥技巧與能力，成為格鬥高手，或者學習工作技能，成為技能導師，也可熱衷培育座騎，成為飼育專家，甚至想成為一位富商，只要你手段高明，有什麼不可以。若你只想如閒雲野鶴，過著隱士般的生活，與世無爭也無妨，假如你有的是雄心壯志，希望能終止亂世，統一天下，此時就必須踏上仕官之路。

 　★ 仕官前的準備

 　　也許渴求一官半職，甚至想籌組義勇軍來獨當一面，但在名聲還未打響，經營能力不夠成熟時，別說是要弄個義勇軍頭目當當，就算去仕官，也可能不受重視。因此，準備脫離在野階段時，不論是提高名聲或加強各種經營能力，都是必須做的功課。

 　★ 如何準備？

 　　你可以到城池的『官宅』裡，接受各種提高名聲為主的工作，比如對城池最直接的『捐獻』工作，或者進行建設城池的『內政』工作，以及當城池發生天災時，協助進行『救災』工作等等。當你有一定的名聲後，後漢帝會賜與你『頭銜』，這代表著你在社會上地位的高低。或是你專心做著同樣一件工作時，也會因為熟能生巧關係，使得這項工作成為你的『專長』，下次再執行這些工作時，會比別人表現更好，這些條件在你日後仕官後，一定會成為有利的競爭優勢！
 『官宅』的工作，會受限於個人『行動力』多寡，決定每天可執行的次數，因此，如何充分利用有限的行動力，亦是出仕前的重要課題之一。此外，除了到『官宅』接洽工作，平時也可四處走訪民間，民眾會對你提出各種需求，小事的話如幫忙砍材、送貨，大事就好比消滅猛獸，解救人質等等。這些請求，大多是不需『行動力』，還可提升經營能力，也是修身的好選擇。

 　★ 當官吧！尋找識才之君

 　　踏上仕官之路時，為了避免懷才不遇，最好的方式是尋找理念相近的主公，否則別說工作不順利，甚至立下各種汗馬功勞後，卻得不到升遷機會，只能自嘆懷才不遇有志難伸，此時若不再趕緊另尋明君，就只好被動的等著某天能遇見識貨的伯樂提拔囉。

 　★ 邁向領導統御之路　

 若不想仕官受人指使，卻又渴望終止亂世，那就試試走另一條路，籌組義勇軍吧！

# 如何成立義勇軍
# http://syfree.chinesegamer.net/sy2_8_2.asp

【三國演義Online】免費經典遊戲任你玩

 　★ 何謂義勇軍？

 　　義勇軍是由志同道合的在野豪傑組成，沒自己的領地，依附各城池中，除了具備組織功能外，還可經營義勇軍根據地，使其自身保有戰力，可視為小型國家勢力。
 義勇軍的規模大小，隨著頭目的領導作風大不相同，若只要好友凝聚一堂，善用組織功能也就足夠，當想擁有城池，攻城掠地，還需積極招募人才，經營根據地，儲備好戰力，才有機會一展雄風。

 　★ 籌組義勇軍吧

 　　若想籌組義勇軍，平時需好好提高『名聲』，當『頭銜』提昇到一定程度時，就可以發起『籌組』義勇軍。此時，籌組者必須先取得其他在野豪傑的擁護，並籌措成立經費，當符合成立條件後，就可『揭竿起義』創立自己的義勇軍隊。而帶頭發起籌組的豪傑，將會成為義勇軍頭目，其擁護者，也會直接成為該義勇軍的一員。

 　★ 如何成立義勇軍

 1.
 籌組者頭銜需為『南中郎將』，名聲需為3000以上才可討取到此頭銜。

 2.
 需有25人擁護，每名擁護者資格必須等級5以上且名聲達到100。

 3.
 繳交義勇軍成立經費『20萬』，依頭目的『定居』城池位置，設定該義勇軍的營地所在。由於義勇軍必須在新手城以外的城池成立，因此請注意頭目不可定居在『許昌、襄陽、洛陽』。

 4.
 以上條件均備齊之後，玩家請點選【團】→【起義】指令，接著請頭目繳交成立經費、輸入要成立的義勇軍名號（唯一），以及義勇軍『暗號』(頭目退位、廢除義勇軍、義勇軍合併等等重要指令用)，即可成立義勇軍。

 成立後所有擁護者，會自動成為該義勇軍勢力的一員。

# 管理制度
# http://syfree.chinesegamer.net/sy2_8_5.asp

【三國演義Online】免費經典遊戲任你玩

 　　義勇軍如同一方小勢力，大頭目位高權重，能否知人善用充實義軍的競爭力，都需要思考全面性的策略。

 　★ 制度的形成

 　　義勇軍是由『階級』及『身份』兩種架構混合的制度，因打著『匡扶漢室』旗幟，制度部分延續傳統，如『階級』的名稱及擢升方式，都受到一定的規範。
 而『階級』越高者，一般會俸祿越高，權限會越大。此外，『身份』代表著你的職務，依照職務有著不同的特殊權限，使各職務之間各司其職，分擔頭目責任。並且，各種『身份』的任免，不受到部將的階級限制，因此如諸葛亮被破格提拔，都是可能的。
 頭目為義勇軍的領導核心，制度的訂定者，平時可依其理念，決定各階級部將所擁有的『權限』與『俸祿』多寡，並依『功績』或自身喜惡，擢升『階級』，賜封『身份』，及給予『封號』。因此在義勇軍階段時，隨著每位頭目的領導方式，每一義勇軍皆有著與眾不同的制度。

 　★ 召開『評定會議』

 　　頭目平時除了『階級管理』、『身份任免』外，最重要的工作，就是召開一月為一期的『評定會議』。會議主要目的是『評定』上期工作成果，這是義勇軍成員擢升階級的參考依據，以及『指派』新的工作目標。
 指派工作時，頭目若能依部將的專長與能力，並參考其提議想執行的工作，達到適才適任，會使工作執行上會更有效率。

 ◎階級評定：分「提拔」及「指派」兩部分。

 提拔部分：
 頭目可以依喜好，或者自行訂定制度，來提拔部將階級。
 ※特別注意：
 在未擁有城池時，各階級不受功績多寡限制，擢昇全由義勇軍頭目決定，但每階級的人數有固定的上限。
 指派部分： 
 頭目可以指派部將在本月做〔捐獻〕，〔監督〕，〔商情〕這三種類型工作，若部將依造頭目的指派進行，會得到額外的績效值，頭目可透過績效值，得知各部將的努力程度。

 　　各位聰明的玩家，是不是已經發現在城池裡多了一個腹地呢？各位可千萬不要小看這個腹地喔，因為它可以通往救災區、義勇軍營地、糧秣房(城池設施，目前暫不收稅)、工作區的重要益口喔，雖然以後要去救災區、義勇軍營地、糧秣房或工作區等地方要多經過腹地這個地方，可是未來這個腹地可是城池的重要設施所在喔。

 兵工廠的位置：在腹地北方靠近腹地入口之處。
 工作區一的位置：往腹地的西南方一路走去即可到達。
 工作區二的位置：往腹地的正南方一路走去即可到達。

 裝　備　庫】
 　★ 製作義勇軍國戰武防兵器的場所。 

 1. 

 如何製作兵器：點選「火爐」就會出現各個製作中的軍備，請只要選擇一樣便可進入製作流程。

 2.

 製作兵器時共有攻擊力、攻城力、裝備性和降低損壞度(防具類的則是防禦力、迴避力、裝備性和降低損壞度)四種屬性可選擇，每次製作時僅能點選其中一種屬性來加強其能力，以”刀”來舉例，確定加強攻擊力屬性後，按下確定之後便會出現材料輸入的表單，選擇適當的材料再按下確定即完成一次製作。

 3.

 舉例來說：當使用「攻擊力」按鍵時，輸入材料為龍骨化石1個，按下確定後，攻擊力點數增加45點，完成度跟損耗度皆會增加8點，若製作的玩家最高技能為冶鐵技能時，會有加成效果，則按下確定後，攻擊力點數會增加75點，完成度會增加4點，損耗度會增加5點。

 【

 軍　備　使　用　須　知】
 1. 

 裝備庫的軍備是提供給部隊所有人使用的，須由頭目在出兵前的編組時妥善分配，例如：裝備庫裡一格有數量10000的刀可分配給一支3000的步兵，一支2000的步兵和一支5000的步兵。

 2.

 2. 在戰場上若是部隊人數減少，則軍備也會跟著減少。舉例來說：一支7000人的部隊裝備7000把刀，若是在戰爭結束後部隊剩下2000人，則放回軍備庫刀的數量則為2000把，另外，在輜重車部隊部分，只要戰爭結束後部隊還有一名士兵存活著，則該輜重車即可保留下來。

# 民心指數升降
# http://syfree.chinesegamer.net/sy2_8_14.asp

【三國演義Online】免費經典遊戲任你玩

 　★ 民心功能的定義

 　　城池民心功能顧名思義，乃是以民心的向背，來決定治理城池的好壞的一種方法。三國演義ONLINE為了讓玩家能珍惜好不容易取得的城池，推出此一功能，希望玩家在攻城掠地之餘，還能治理好轄下的城池，以免民心思變，造成不可預期的後果。
 　　基本上，民心功能只針對已經被玩家攻佔的城池才會有效果，仍屬於NPC所佔領的城池，民心功能並不會開始啟動。一旦當玩家攻陷了NPC所佔領的城池，民心功能中的「民心指數」便會開始計算，一開始民心指數皆為100，系統將視玩家義軍組織治理城池的績效，每個月予以評比。至於成功打下原本由其他義軍所屬的城池時，新的城池所有人將繼承前一個所有人所遺留下來的民心指數。 

 　★ 民心指數的升降

 　　民心指數一開始均為100，影響其升降的因素，就是城池稅率過高！自古以來正所謂「苛政猛於虎」，對老百姓來說，其影響最大的，莫過於沉重的賦稅了。因此在三國演義ONLINE的世界中，如果城主對於轄下城池課徵過高的稅率的話，民心指數也會在每月初一時下降4點。 所以，城主們要注意啦！！雖然稅率調高會讓你的財富大量積聚，但是這之後人民將會離心離德，所有後果可要玩家自己承擔囉！
