# S01e 三轉任務 `promote_test2` 提案（未經用家 confirm）

## 攻略原文重點
- 原版**三轉任務只有一條**（七彩項鍊），六職共用，冇分職業任務。
- Lv100、新野城找**諸葛亮**觸發，完成條件「七彩孟獲打敗」。
- 7 色晶，每色：打該色孟獲 → 得晶 → **帶住孟獲（跟隨 ≈120 分鐘）**去關鍵人物換真晶。

| 色 | 打孟獲處 | 換真晶人物 |
|---|---|---|
| 紅 | 宛洞 | 長沙 曹操 |
| 橙 | 潼關 | 江夏 劉備 |
| 黃 | 桃花渡 | 南皮 孫堅 |
| 綠 | 濮陽洞 | 北海 曹丕 |
| 藍 | 幽州 | 平原 劉禪 |
| 靛 | 襄平洞 | 天水 孫策 |
| 紫 | 黑山洞 | 下邳 孫權 |

- 死亡跌返 99 級，要練返 100 先可繼續。
- 通天關（24 魔神）只係「夢幻道具」→ 換三轉裝備，**唔係**轉職條件。

## 現有基礎
- `promote_quest_id(tier)` 三轉 = `promote_test2`（未有資料）。
- 七彩奪寶陣場景已做：7 色魔孟獲逐層，掉 `63013 七彩真晶`（紫靛藍）/ `63014 七彩天鑽`（綠黃橙紅）。
- 任務 `escort` stage（NPC 跟隨去目的地）已有（王允連環計貂蟬）。
- 二轉 `promote_test_<職>` 結構：talk → collect → talk(done) → 角色面板撳「轉職」。

## 方案 A（簡化，建議）
全職共用一條 `promote_test2`，Lv100 + 已二轉：
1. 新野 諸葛亮 對話接任務（六職各一段對白，講明三轉職名：猛將/女將/聖君/妖姬/諸葛/聖女）。
2. 入七彩奪寶陣，打 7 色魔孟獲，收齊 **7 件七彩晶**（用現有 63013×4 + 63014×3，唔使加新道具）。
3. 返新野交諸葛亮 → 角色面板撳「轉職」。
- 死亡懲罰：唔跌級（單機，簡化）。
- 優點：用晒現成場景/道具，改動細。

## 方案 B（照原版）
7 條分支：七色晶（要新 7 晶 + 7 真晶道具，items 係生成檔，要改導入器/補自訂道具）+ 7 個場景（宛洞/潼關/黑山洞等未必齊）+ 孟獲跟隨 120 分鐘 + 7 個換晶 NPC。工程大，場景同 NPC 要先補。
