## 4. 戰棋核心（【自訂】簡版）

- 地圖：格仔戰場（歷史戰役專用場景，`scenes.json` battle 型），50×50 格。
- 部隊 = 玩家 1~4 支部隊（每支 ≤7000 兵）+ 武將同伴部隊（第 4 部隊位【原】）。
- 半即時：
  - 玩家操控 = 點部隊 → 點目標（行去/攻擊/攻城/撤退）——同主遊戲觸控一致
  - 每 tick（0.1s）部隊自動交兵：兩支部隊相鄰格 → 每秒互相扣兵數 = 攻 × 兵量 × 兵種對剋表 / 防
  - 士氣【原 宴會專長提士氣】：0~100，士氣低 → 攻 ×(士氣/100)；士氣跌 = 戰友陣亡/被包圍
- 指令【原】：

| 指令 | 效果 |
|---|---|
| 出戰編組 | 開戰前 1 小時君主編組（每場 30 人制→單機 = 綁定武將同伴名單） |
| 宣戰 | 君主，週日 18~20 點窗口（遊戲日曆）；消耗行動力 50【原】 |
| 攻佔城池 | 攻城車打破城牆（要塞 HP）→ 步兵進城 → 城戰 |
| 撤退 | 部隊退出戰場（保留剩兵） |
| 強援 | 有 2 台輜重車 + 補給專長【原】→ 大範圍回兵力 |
| 計策 | 登用武將/文官每場 1 次（不限計策值【原】）→ 效果 = 士氣全滿/敵士氣 -50/全軍防 +20% |

## 5. 宣戰節奏（【原】規則，時間改遊戲日曆）

- 義勇軍（無城池）：只能對定居城池宣戰（【原】）
- 有城池勢力：只能對鄰近城池宣戰【原】；唔可以對城內在野勢力宣戰
- 場次：每週一至日，一小時一場；宣戰週日 18~20 點提出 → 系統排下週場次（優先順序照【原】表）
- 和談/取消：週一~六 18~19 點；週日 20:30~21:30；取消後一週唔可以再對嗰城宣戰【原】
- 單機化：時鐘 = 遊戲日曆（現實 72 秒 = 1 日 → 每週 8.4 分鐘一循環）；全部 NPC 勢力模擬各自宣戰/防守（世界層要「勢力模擬」：每月結算領土變化【自訂】）

## 7. 城池攻防（【原】理念延伸）

- 要塞/城牆 HP（防禦屬性 ×100 係數）；攻城車先打破先入得
- 佔領後：民心啟動（Spec 08 §9）、稅率設定（法令）、新城池 = 勢力領土 → 可以繼續宣戰
- 佔領限制【原】：A 攻 B 後，C 原本排定攻 B 嘅場次照行（要防守）

## 8. 世界勢力模擬（【自訂】後台）

- 每 city：勢力（NPC 勢力 6 個：曹操/劉備/黃巾殘黨…）或空缺
- 每月結算：NPC 勢力之間照 §5 規則自動宣戰/打一場簡化戰（兵力 = 勢力帶兵總和 × 士氣）→ 領土變化 → 市場加權/任務 NPC 出現位置
- 玩家勢力加入同一系統；玩家可選擇「手動」或「交畀 NPC 代理」啲防守線
