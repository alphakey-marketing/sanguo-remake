## 1. 座騎總覽（【原】）

- 兩種：**一般座騎（馬）** = 代步 + 馬戰；**戰騎（野獸）** = 戰鬥/輔助，速度較慢。
- 馬廄（`facility_stable`）買馬/飼料/寄養/放牧；最多 **5 匹馬**【原】；戰騎最多 **3 隻**【原】。

## 3. 座騎屬性（【原】9+ 欄）

| 屬性 | 影響 | 提升方式 |
|---|---|---|
| 生命力 | 歸 0 = 死亡（馬瘟/創傷/衰老） | 醫療 |
| 學習力 | 成長速度（成年後） | 贈送禮物（道具） |
| 爆發力 | 放牧狀況效果 | 教導訓練（道具） |
| 奔跑力 | 騎乘速度 | 陪伴玩耍 |
| 忍耐力 | 疲勞度上限 | 責備處罰（降情緒） |
| 體力 | 疲勞回復速率 | 餵食（飼料） |
| 飽食度 | <50 疲勞唔降 | 餵食 |
| 親密度 | ≥60 先騎得 | 帶喺身邊/情緒高 |
| 情緒 | 高興/難過/生氣/普通/一般/@_@ | 玩耍↑ 責備↓ |
| 疲勞度 | 滿 = 頭暈（放馬廄過子時恢復） | 放牧/休息 |
| 優秀值 | 每 +1 級 → 1 點分配 5 屬性 | 放牧成長 |

- 生命週期：襁褓期（30 game 日【原】）→ 成熟期（屬性停，靠放牧/戰鬥成長值）→ 衰老期（死亡前 30 日提示）→ 死亡（365 日上限【原】；可以繁衍留後代）。

## 5. 放牧（【原】）

- 道具「馴馬專用哨」使用 → 放牧 / 召回；每次**一個時辰**【原】。
- 返嚟觸發狀況（種子 RNG）：無事 / 成長（優秀值 +1，屬性成長）/ 執到嘢（武器防具/藏寶圖）/ 受傷（生命力降/異常狀態）；爆發力愈高好結果機率愈高【原】。
- 疲勞增加（表格【原】：身邊→增加，被放牧→放牧成果…照錄）。
- 離線（單機 = 離開 game）時放牧中馬 → 上線即返【原】。

## 6. 繁衍（【原】sy2_4_4/5）

- 性別：買返嚟一係母（買公馬要去畜牧型城池：長沙/桂陽/江夏【原】）。
- 配種：同擁有公馬嘅人組隊（單機 = 同武將同伴？→ 設計：**馬廄老闆提供「種馬借用」服務**（收 5000 金），免第二玩家）；許昌馬場「配種」指令。
- **胎教小遊戲**（【原】）：動力值 50 起、每日子時 +20（<50 時 +40）；選「奔跑/睡眠/鞭打/喝水/訓練」下注 → 跑馬燈停啱 → 得積點（賠率）；胎氣 +1/次，100 胎氣出生；「懶人胎教」= 放牧場 1 game 月自動生（上限低）。
- 積點分配：照 §2 兌換錶（例：烏孫馬 3 點 → +1 爆發力上限）；**總積點 ≥ 500~1000（品種而定）→ 進階馬**【原】。
- 小馬品種 = 父母其中一（母血機率 ×2【原】）；性別多數母（公 = 明日之星）；小馬 3 個月未提領死亡【原】。

## 7. 騎乘與馬戰（【原】sy2_4_3/7）

- 親密度 ≥60 騎得；騎上 = 移速 +50%（奔跑力調）+ 可以馬戰武器攻擊（同一般武器互斥）。
- 馬戰兵器（破刀/破劍/破槍 50 攻 10 級 → 掩月刀/七星劍/龍膽槍/…300 攻 100 級）表數據化 `data/mount_weapons.json`。
- 馬戰特技 9 招（Spec 02 §10）——最多學 3 招；師傅（馬廄 NPC，金錢）+ 任務獎勵。
- 受擊/攻擊傷害分配【原】：NPC 攻擊騎乘玩家 → 玩家食傷；玩家主動攻擊 NPC → 座騎食傷（戰騎 PK 規則 Spec 02 已有表）。

- 跟玩家打怪吸 exp；升級畀 3 種點數：

|---|---|---|---|

| 26~50 | 3 | 1 | 3 |

- 戰鬥特技成本：每級 1 點（最高 10 級）；「*」技能需上一招 5 級先學得 + 唔可以高過上一招等級【原】。

### 8.5 忠誠 / 交易 / PK（【原】sy2_5_1/6、sy2_5_7）

- 忠誠度：戰鬥死亡 −1【原】；過低 → 走佬（離隊消失）；交易 −5；忠誠 <5 唔可以交易；玩家 <10 級唔可以交易。
- 戰騎複數量：最多 3；身上有戰騎/座騎唔可以買新（要放馬廄）。
- PK：玩家打玩家、戰騎打戰騎；騎乘中徒步攻擊 → 玩家食傷、騎者要落馬先反擊；戰騎 PK 死亡 → 返許昌馬廄 + 忠誠 −1。

## 10. 測試要點
- 六馬屬性/進階門檻（500~1000）正確；積點兌換錶
- 親密度 ≥60 騎得、疲勞滿頭暈、放馬廄過子時恢復
- 放牧狀況 RNG：成長/執嘢/受傷機率跟爆發力
- 戰騎 10 種屬性總和 19；升級點數表；技能點成本（戰鬥 1/級、友好 3/6/12/24/級、跨種 ×3）
- 戰鬥技能「*」前置（5 級）+ 唔可以高過前一招
- 忠誠機制：死亡 −1、<5 唔交易、過低走佬
- 馬戰兵器等級限制 + 特技 3 招上限 + 對應武器檢查
