## 2. npc_drops.csv（1319 NPC，488 有掉落）→ `client/data/monsters.json` 掉落來源

- 格式：`npc_id, npc_name, hp, n_drops, drops(item×rate)`；rate 基數 100000（例：甜蘿蔔@30000 = 30%）
- 導入器：`tools/import_drops.py`（新寫）：
  1. 揀等級帶怪（Spec 04 §2 分區表）
  2. rate → p = rate/100000；p ≥ 0.05 → 常用掉落；< 0.05 → 稀有掉落（合併落 `dropTables`）
  3. hp 已有（攻略/表）就照用，冇就模板生成（Spec 04 §1）
  4. 對應 items.json 校驗 id，報 missing
- ⚠️ 已實作怪物（田鼠/野狗…）drop id（61501 田鼠碎骨）都喺 items.json ✅
