# Spec 02 — 戰鬥系統

> 對應攻略: sy1_2_1(入門)、sy2_1_1~3(職業攻擊類型)、sy2_9_1(攻防型態)、sy2_10_1~6(武器/防具/寶石/術書)、sy3_7(特技絕招缺頁)、sy2_5_7(戰騎 PK)
> 現有實作: `client/rules/combat.gd`、`sim.cmd_attack`、`sim._think_*`（即時制 10Hz）
> 【原】= 攻略明文；【自訂】= 自己設計。

## 1. 即時制總則（【原】已實作）

- sim 權威，tick = 0.1 秒（受 clock 驅動）；client 只發意圖（點怪/發技能）。
- 攻擊模式三種【原】：物理（近/中/遠距武器）、術法（耗 MP、吟唱、遠距、大範圍）、絕招（耗 MP+SP、大範圍、需習得）。
- 移動/攻擊由 10Hz tick 判定；怪物 AI `_think_mob` 已有（仇恨/追擊/返回）。

## 2. 物理攻擊【原】

| 項目 | 【原】 | 【自訂】公式（已實作 + 擴充） |
|---|---|---|
| 威力 | 武力 + 武器強度 | 見下 |
| 攻速 | 敏捷 | attack_interval = max(6, round(20 − agi×0.5)) tick |
| 命中 | 武器命中率 | hit_chance = clamp(0.8 + (hit−45)/200 + 等級差×0.02, 0.3, 0.98) |
| 射程 | 武器類型 | 近 melee=1、中=2、遠=5 格（切比雪夫） |
| 防禦 | 防具物防 | 見下 |

- 智力系術（地水火風之術）= 智力；靈力系術（葉針雲/咒術/恢復）= 靈力【原 sy2_1_4】。

- 大範圍施放 = 圓形範圍 3 格【自訂】，全部敵人都食傷害，隊友唔受（有「攻擊範圍」設定【原】）。

### 3.2 屬性相剋（【原】地剋水、水剋火、火剋風、風剋地）

- 怪物/武將有屬性：地/水/火/風/無（`monsters.json` 加 `element` 欄）。
- 加成：攻擊方屬性剋目標 → ×(1+0.5)×寶石加成；被剋 → ×(1/(1+0.5))（【自訂】基數，寶石另計）。
- 寶石製：裝備屬性石（`ch.equip.jewel` 兩位：攻擊石 1 + 防禦石 1【自訂】；武將寶物同一欄位規則 Spec 09）；每階 +10%【原 10%~100%】。

## 4. 寶石（【原】sy2_10_5 神奇寶石 + jewel.csv 實錘）

- 資料源：`D:\Download\sanguo\extracted\text\jewel.csv`（204 粒）+ 攻略表（40 粒屬性石 + 輔助/特殊石）→ `data/jewels.json`。
- 種類：
  1. **屬性之石**：風/地/水/火 ×10 階（10%~100%），例：飄嵐之石(風+10%)…盤古之石(地+100%)；無之石/生之石（特殊，任務用）
  2. **輔助效果**：HP/MP 上限%、SP 上限點、物攻/術攻%、物防/術防%、物迴/術迴%（著裝即生效）
  3. **特殊效果**：融合材料（大宗師合成，Spec 05）、武將寶物、將軍令兌換
- 裝備：同武器防具咁裝（戒指欄或專用寶石欄【原】「裝備方式與一般武器防具相同」→ 設計：**戒指欄 2 格** = 首飾 + 寶石共用；改為專用「寶石」欄 2 格，與戒指互斥都唔得，最直接：寶石欄 1 格攻擊用）。
- 取得：打怪掉落（npc_drops.csv）、工作合成（大宗師）、任務（歷史任務畀 4 屬性石，Spec 06）、商店（低階）。

## 11. 測試要點
- 物理傷害向量（已有 201 條）；改動公式要更新向量對拍
- 術法：mp 唔夠唔施得、吟唱被打斷、範圍命中多敵人
- 屬性相剋：5 屬性 × 5 屬性全組合表
- 寶石：裝備 +10%~+100% 加成正確；同類覆蓋
- 絕招：MP/SP 消耗、冷卻、範圍、需要武器檢查
- 狀態：封咒後術法失敗、中邪唔郁得、buff 時限到解除
