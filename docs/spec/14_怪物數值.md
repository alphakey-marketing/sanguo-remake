# Spec 14 — 怪物數值 / 等級 / 經驗平衡（2026-10-02，【自訂】）

> 取代 spec 04 §1 嘅 hp=10×lv²+20 / atk=3×lv+4 模板（全部怪；舊手寫怪 boss 另有倍率，見 §6）。
> 參考：原版 `Npc_table.tsv`（hp/atk 欄只係強弱指標，唔係等級；原版冇 exp 欄）、用家提供嘅 180 級升級表。
> 實作：`client/rules/exp_table.gd`、`client/rules/mob_scale.gd`、`client/data/mob_curve.json`、`tools/balance_monsters.py`、`tools/sim_balance.py`。

## 1. 設計目標
- 殺同級怪：打 3（Lv1）～21（Lv180）下死怪，每隻抽走玩家約 12%（Lv1）→25%（Lv60+）血量（未計防具、藥水、同伴）。
- 升一級要殺幾多隻（`mob_curve.json kills`）：Lv≤10 5 隻、≤20 8、≤40 12、≤60 20、≤80 30、≤100 45、>100 60。舊「一直 5–8 隻升一級」已取消。

## 2. 數值曲線
- `mob_curve.json anchors = [等級, hp, atk, def]`，之間按對數內插（def 有 0 值用直線），超出兩端沿用端點。
- 錨點由 `tools/sim_balance.py --solve` 推出：玩家模型 = 全點武力、武器強度 max(10, 2.5×Lv)（items.json 各級最強武器約 2.5×等級）、攻速 max(6, 20−敏×0.5) tick，怪攻速 20 tick；怪 def = 0.6×Lv。
- 強弱系數 `f = clamp((原版怪表 hp / 80)^0.5, 0.7, 1.8)`：hp ×f、atk ×√f、def 不變。表冇嘅怪（合成 id 70000+）f = 1。
- exp = 升級表該級需要 ÷ kills；gold = [0, 3×Lv]。

## 3. 生成
`import_orig_monsters.py` → `import_drops.py`（×3 至 --check OK）→ **`balance_monsters.py`**（冪等；`--check` 已接入 run_tests.sh）→ `import_orig_assets.py --sets mon`。monsters.json 係生成檔，唔好手改。

## 4. Spawn 級別覆蓋
- `monsters.json spawns[].lv`（可選）：呢個 (怪, 地圖) 嘅等級。引擎 `GameData.mob_def(def_id, lv)` 用 `RulesMobScale.scaled` 將基準數值按曲線比例縮放（有快取），`e["mob"]["lv"]` 記錄。
- 洞穴每層 lv = `cave_level(城, 層)`（CAVE_BAND 線性）；外圍野怪夾住攻略等級帶（兗徐 10–20、其餘 1–10）。同一隻怪跨層會出唔同等級。

## 5. 驗證
`python tools/sim_balance.py` 印出各級「打幾下死怪 / 損失血% / 殺幾多隻升級」。調曲線：改 `sim_balance.py target()` 或 `mob_curve.json`，再跑 balance_monsters.py。
