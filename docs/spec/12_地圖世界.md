# Spec 12 — 地圖世界（多地圖 + 大地圖）

> 動機：舊版成個世界係一張 128×64 格仔，許昌城 26×26、城外 35×35，全部色塊，冇路冇河冇地名，冇三國感。
> 參考：三國群英傳M（大地圖按州郡 + 逐張場景圖 + 自動尋路 + 小地圖），全部【自訂】實作。
> 決定（2026-09-23）：B 檔（多地圖 + 大地圖）、俯視 tile、人手畫地圖 + 史蹟地標。

| 期 | 內容 |

## §2 地圖檔
- `data/maps.json`：`legend`（字元 → 地形）、`maps[]`、`landmarks[]`、`world`（大地圖城池節點）。
- 每張地圖：`{id, name, file, ox, oy, safe, kind(city/field/cave), city?, areas[]}`；`file` = `data/maps/<id>.txt`，一個字元一格，每行一樣闊。
- `ox, oy`：地圖喺**全域格仔**嘅左上角。全部地圖拼埋一張 `Sim.W × Sim.H` 大網格，地圖之間留空（void = 行唔到）→ sim 所有距離/範圍計法唔使改，唔同地圖永遠唔會「隔籬」。
- 其他數據（商店/設施/任務 NPC/傳送點/spawn area/地標）一律寫 `"map": <id>` + **地圖內座標**，GameData 載入時轉全域座標（保留 `lx, ly`）。
- 每張地圖自動生成一個 zone（id = 地圖 id，safe 跟地圖）；舊 zone id 保留（`field_1` = 潁川郊外、`runan_f1..10`、`town` = 許昌城）。

## §3 移動
- 玩家/居民 `cmd_move`：A* 4 方向尋路（決定性，同分先比插入次序），路徑存 `e.path`（全域格 index），`step()` 每 tick 行一格；`tx,ty` 被其他邏輯改咗（追怪）就作廢路徑、行返直線。上限 6000 節點，搵唔到 = 直線。
- 追擊（`_think_player`）：目標喺視線直線被擋先用 A*（上限 800）。
- 怪物：維持直線（練功區開揚）。

## §4 過圖
- 傳送點加 `auto: true` = **踩上去就過圖**（城門/地圖邊/洞窟樓梯）。只有「今 tick 行咗上去」先觸發，傳送落地唔會即刻彈返轉頭。
- `cmd_travel` 照舊（要行近），互動掣「傳送」保留。
- 跨圖路由 `_route_to_map(e, map_id)`：地圖圖（傳送點 = 邊）BFS 搵第一跳，行去嗰個門口。居民返客棧/落野區用佢。

## §5 地標 / 區名（歷史感）
- `areas[]`：地圖內命名區域（例：許田圍場、許下屯田、潁水渡口）；行入去 HUD 彈區名橫幅。
- `landmarks[]`：`{id, map, x, y, r, name, text}`；玩家第一次行入 `r` 格內 → 事件 `landmark` + 訊息（典故一段），記入 `ch.landmarks`（存檔）。暫時冇獎勵。

## §6 UI
- 地圖貼圖：每張地圖載入時預渲染一張 Image（每格 16px，程序化像素細節，種子 = 座標），`_draw` 只畫當前地圖一張貼圖；夜晚用 modulate 變暗。
- 鏡頭限喺當前地圖範圍（地圖細過畫面就置中）。
- 小地圖：右上選單列下面 112×52，當前地圖縮圖 + 自己（黃）/怪（紅）/NPC（藍）；撳 = 開地圖面板。
- 地圖面板：頁籤「區域」（當前地圖大圖 + 地標名）/「天下」（豫州荊州城池節點 + 路線，未開放 = 灰）。

## §7 驗收（B1）
- 地圖檔每行等闊、字元全部喺 legend；所有傳送點/商店/設施/NPC/spawn/地標落喺行得嘅格。
- 每張地圖行得嘅格全部連通（由入口 BFS 行晒）。
- A* 繞過河/屋；路徑決定性；存檔 roundtrip 帶路徑一致。
- 踩城門自動過圖；落地唔會彈返；居民由城入面自己行出野外打怪。
- 全部舊測試改用數據座標後照過。
