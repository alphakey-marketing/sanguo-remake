## 2. 加減原則（【原】規則，單機化執行主體）

| 【原】規則 | 單機化執行 |
|---|---|
| 殺善玩家 → 自己係正/善：直接扣成 −1000 | NPC 居民/武將有 alignment（居民 NPC 正善、怪/賊負）→ 殺善 NPC（居民）= 打落 −1000 |
| 惡人（負值）殺善玩家：累積 −1000 | 同上：負值玩家殺居民再 −1000（累積） |
| 善/中立殺紅人（殺人魔玩家）：+300 | 殺「紅名 NPC」（居民警告話你知佢係殺人魔）或 PK 入侵者：+300 |
| 紅殺紅：+300 | 殺人魔 NPC 互殺：+300 |
| 反擊主動攻擊者成功：+100 | 被 NPC/武將先攻擊，成功反殺：+100 |
| 殺善 NPC 扣、殺惡 NPC 加 | 已實作：`karma_after_kill`（alignment/10 取整）；惡怪殺得越多善惡越高【原】 |
| 救災/任務/捐獻 => 善惡不變（名聲另計） | 同上（善惡同名聲分開，Spec 08） |

- 數值校準【自訂】：
  - 殺 1 隻田鼠（alignment −10）→ 善惡 +1
  - 殺 1 個居民（alignment +300 檔）→ 即跌落 −1000 檔（一次過【原】）
  - 殺 1 個賊頭目（alignment −2000）→ +200
- **目擊**（已實作）：玩家殺任何有 alignment 嘅目標，附近（8 格）NPC 都會記錄（`NpcMemory.witness`）→ 影響好感/傳聞/衛兵態度（Spec 09）。惡名遠播：每次殺善 NPC 會傳聞擴散，令更多 NPC 對你態度轉差【自訂】。

## 4. 死亡處分（【原】數字全表）

### 4.1 掉裝備（死亡時身上物品，最高 N 件）

| 善惡值 | 最高掉落件數（每件獨立機率） |
|---|---|
| ≤ −16001 | 7 |
| −8001 ~ −16000 | 6 |
| −1001 ~ −8000 | 3 |
| −1000 ~ +1000 | 1（高機率） |
| +1001 ~ +8000 | 1（較高機率） |
| +8001 ~ +16000 | 1（普通機率） |
| ≥ +16001 | 1（較低機率） |

- 機率【自訂】：善劣兩邊用 0.8 / 0.6 / 0.4 / 0.3 / 0.25 / 0.2 檔（惡越高跌得越多件 × 每件機率越高）。
- 已裝備 item 都計入「身上可掉物品」【原】（掉落優先裝備槽，其次背包，隨機）。
- **幸運符**【原】「死亡唔會掉物品」：身上有 → 唔跌（消耗 1）。

### 4.2 掉經驗（【原】數字）

| 善惡值 | 扣該級所需經驗 |
|---|---|
| ≥ −1000 | 10% |
| < −1000 | 20% |

- **護身符**【原】：經驗損失減半（消耗 1）。
- **還魂丹**【原】：死亡時自動復活（原地/客棧，唔掉物品唔掉經?）→ 設計：還魂丹 = 死亡即喺客棧復活，物品/經驗照常掉落（同【原】「還魂丹啱復活」），冇死就唔會消耗。

### 4.3 死亡流程（已實作 + 新增）

1. 扣經驗（死亡掉經驗規則）
2. 掉物品（幸運符擋）
3. 傳送返客棧：HP/MP/SP 回復一半【自訂】（原版復活後唔滿，要訓覺/食）
4. 記事件：附近 NPC 目擊死亡（好感微升：同情 −5？→【自訂】善 NPC 對死過嘅人好感 +2）
5. **裝備耐久**：每件裝備扣 10% 耐久（【自訂】；同時係修理服務需求根源）
6. 天譴情況先判定（§3）

## 5. NPC 態度（【原】惡值高買嘢貴；數字【自訂】已實作）

- `RulesKarma.price_factor`：中立或以上 = ×1.0；罪犯 +10%、惡人 +20%、殺人魔 +30%。
- 衛兵/任務 NPC：罪犯以下 → 唔接受官令任務；殺人魔 → 唔俾入城（法令容許除外）。NPC 好感係微觀調節（Spec 09），善惡係鉅觀開/關。
