# Spec 01 — 角色與成長系統

> 對應攻略: sy1_1_2(人物設定)、sy1_2_11(提升等級與屬性)、sy2_1_1~3(職業)、sy2_1_4(人物屬性)、sy2_2_1(技能型態)、sy2_8_1(經營之路)
> 現有實作: `client/rules/stats.gd`、`client/rules/expert.gd`、`client/rules/class.gd`(二轉/三轉)、`client/data/classes.json`、`client/data/experts.json`、`sim.cmd_facility`(練兵場/私塾/寺廟)、`sim.cmd_class_promote`
> 【原】= 攻略明文；【自訂】= 自己設計，攻略無數值。
>
> 現狀 (2026-10-03，待用家手測)：滿級 180、屬性上限 500、滿級多出 exp 20:1 換金、擊殺 exp 按怪/玩家等級差調整、建議分配先預覽後確認。HP/MP/SP 隨職業：`classes.json` 的 `vit` (hpMult/mpMult/spMult/hpAttr)，取代舊 `4×武力`【自訂】。升級自動派點 `ch.autoPoints` 預設關、無 UI，只由 sim 指令 `cmd_auto_points` (debug) 開。

## 2. 理念測驗（【原】五理念；題目與計分【自訂】）

理念 = 義理 / 霸權 / 權謀 / 隱遁 / 治國。**決定了就唔可以改**（刪角色先得）。

- 測驗：**12 條情境題**，每題 2 個選項，每選項對兩種理念 +1（互相牽制令分布更平均）。
- 例題（實際題庫放 `data/quiz.json`，可以繼續加）：

| # | 情境 | 選項 A | 選項 B |
|---|---|---|---|

| 2 | 主公要你獻計攻城 | 陽謀堂堂正正（霸權+1） | 收買內應（權謀+1） |
| 3 | 戰亂後田地荒廢 | 放下刀劍，教民耕種（治國+1） | 遠走山林，不過問世事（隱遁+1） |
| 4 | 好友邀你共謀反叛朝廷 | 忠於朝廷拒絕（治國+1） | 跟好友共進退（義理+1） |
| 5 | 山林隱士贈你藏寶圖 | 即刻動身尋寶（霸權+1） | 留待有緣人（隱遁+1） |
| 6 | 城池糧倉起火 | 拋下一切去救火（義理+1） | 趁亂查倉庫帳目（權謀+1） |
| 7 | 君主昏庸 | 輔助太子取而代之（霸權+1） | 辭官返鄉耕田（隱遁+1） |
| 8 | 村民求你主持公道 | 立規矩罰壞人（治國+1） | 調解咗就算（義理+1） |
| 9 | 敵軍兵臨城下 | 建議投降保全百姓（治國+1） | 偷襲敵營（權謀+1） |

計分最高者 = 理念；並列時按權重（義理>治國>霸權>權謀>隱遁）。

## 4. 三大值（【原】HP/MP/SP 定義，公式【自訂】已實作）

| 值 | 消耗 | 回復 |
|---|---|---|
| 生命力 HP | 受傷 | 客棧睡覺/吃食物/煉丹品/超渡特技 |
| 精神力 MP | 術法、部分絕招 | 客棧喝茶/藥品/煉丹品 |
| 體力 SP | 初階工作、職業特技、絕招 | 客棧睡覺/練兵場小兵免費回復(【原】)/食物 |

- 公式（`RulesStats`）：max_hp = 60 + lv×15 + str×4；max_mp = 20 + lv×5 + spi×3 + int×2；max_sp = 50 + lv×3 + agi×2。
- **每刻自動恢復**【自訂】：(刻 = 8 刻/時辰，96 刻/日)。站喺城內安全區：每 6 刻回 1% max（hp/mp/sp）；野外唔會回復（鼓勵回城）。戰騎「聖體」友好技可加倍（Spec 07）。
- 等級提升即回滿三值（已實作）。

## 5. 等級與經驗（【原】5 級脫新手、50 二轉、100 三轉；曲線【自訂】已實作）

- exp_to_next(lv) = **用家提供升級表**（2026-10-02 取代舊公式 round(20×lv^1.8)）：Lv1 需 10、Lv2 20、Lv5 50、Lv10 175 … Lv100 約 3.4 千萬級、Lv180 需 1,083,025,800。全表 180 級喺 `client/rules/exp_table.gd`（`RulesStats.exp_to_next` 查表）。怪 exp 同呢張表掛鉤（每級殺幾多隻升級見 spec 14 §3）。
- **升級 → 玩家自行分配點數**【自訂，取代舊自動 growth】：
  - 每升一級 → `ch.attrPoints += 3`（點數數值可調）
  - `sim.cmd_raise_attr(attr)`：扣 1 點，`str/agi/int/spi` 其中一個 +1（**政治/魅力唔可以用升級點**【原】只能私塾/寺廟）
  - 新手唔想諗 → UI「自動分配」掣（按 `classes.json.growth` 比例自動派，一鍵）
  - `classes.json.growth` 由「升呢自動加」改為「自動分配建議比例」（純 UI 提示，唔再強制）
- **歷練**（【原】練兵場）：每 10 歷練 → 下次升級 武/智/敏/靈 +1（已實作 cap 100，同自由點數並存，升級時一齊入）
- 5 級前新手保護（【原】）：
  - 客棧店小二免費補 HP（5 級前）；5 級後收費 5 金（`shops.json inn.restCost`）
  - 系統介面 4 鍵 → 5 級後 6 鍵（UI 層）
  - 神秘老人（新手任務序章，Spec 06）
- 死亡掉經驗按善惡（Spec 03）。
