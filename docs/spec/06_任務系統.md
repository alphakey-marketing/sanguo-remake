### 1.2 sim 指令

| 指令 | 作用 |
|---|---|
| `cmd_quest_talk(npcId)` | 對話時檢查 `pre` → 觸發/推進 stage |
| `cmd_quest_turnin(npcId, questId)` | 繳交收集道具/覆命（官令/救災） |
| `cmd_quest_answer(questId, answerIdx)` | 文官問答/測驗（登用、任務題目） |
| `cmd_quest_battle(questId)` | 武將 PK 擂台（登用/任務頭目） |
| `cmd_quest_daily(questId)` | 官令指定工作執行 |

- 每 tick 檢查 `pre.window`（時辰窗口【原】好多任務有時限）；quest 進度存 `ch.quests = {questId: {stage: 2, ...}}`；完成記錄 `ch.questDone`。
- 任務道具 = `items.json` cat 任務物品/任務雜物（61501 田鼠碎骨…）；任務道具唔可以賣（flag，賣錯會阻任務）。
- UI：記事功能【原】「記事」幫你記觸發過嘅任務 + 提示 → `mobile` 任務頁籤顯示進行中任務同下一步提示。
