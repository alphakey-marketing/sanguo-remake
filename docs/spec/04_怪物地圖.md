## 1. 怪物資料導入流程（用解咗嘅表）

`npc_drops.csv` 有 488 隻怪帶掉落（item id × rate/100000？實例：`銅鎚(10039)@200` = 0.2%）。`Npc_table.tsv` 有 hp/mp/atk。導入程序：

1. 由攻略怪物大全篩「豫州+荊州」等級帶怪（§2 分佈表）
2. 用 `npc_drops.csv` 對應 id 攞真實掉落，rate 換算做 p（rate/100000，min 0.0001 保留稀有掉落）
3. 以 `items.json` 校驗 item id（6068 件內）；掉落機率 >5% 嘅先入「常見掉落」，其餘入「稀有掉落」表
4. 數值模板【自訂】生成 hp/atk（攻略只有部分怪有 hp，其他用模板）：

| 等級帶 | hp 基準 | atk 基準 | def 基準 | exp 基準 |
|---|---|---|---|---|
| 1~5 | 20~70 | 4~12 | 0~3 | 6~24 |
| 6~10 | 120~260 | 16~26 | 5~8 | 45~110 |
| 11~20 | 300~800 | 30~55 | 10~16 | 120~280 |
| 21~35 | 900~2200 | 60~100 | 18~30 | 300~600 |
| 36~50 | 2400~5000 | 110~180 | 32~48 | 650~1100 |
| 51~70 | 5500~12000 | 190~320 | 50~75 | 1300~2600 |
| 71~90 | 13000~40000 | 330~600 | 80~120 | 3000~8000 |
| 91~100 | 45000~300000 | 650~1500 | 130~200 | 10000~60000 |

- hp/atk 模板方程式（v1 已用）：hp = 10×lv² + 20；atk = 3×lv + 4（誤差 ±20% 隨機化，種子 RNG）。
- exp 基準 vs 升級曲線（Spec 01 §5）：確保「殺同級怪 ≈ 5~8 隻升一級」手感。
- gold 掉落【自訂】：冇機率= 0；有 = [0, lv×3]。

## 6. 掉落機制細節

- `npc_drops.csv` rate 基數 = 100000 分之幾。跌 $ 實測例：甜蘿蔔(29042)@30000 = 30%。（轉換率寫入導入器，v1 已用 0.5/0.4/0.3 等手工值，§1 程序正式替換）
- 金錢直接入袋；物品會以「跌落地」形式出現（`sim` 加 `dropped` entities：存在 300 tick 後消失；戰騎「撿寶」友好技自動執【原】Spec 07）。
- **稀有掉落再分層**【自訂】：資料 p<0.5% 嘅掉落唔受「幸運」影響；v1 冇幸運概念，記住就得。
- NPC 掉落（武將/居民）= 佢身上裝備 + 背包（`_kill_mob` 擴充到 NPC 死亡（PK）——類比死亡掉物品但機率 +20%「賊性」）。
