## 1. 義勇軍成立（【原】sy2_8_2 全條件；**S08e 已實裝**）

1. 頭銜 = 南中郎將（名聲 ≥3000）【原】
2. **25 人擁護**（每人 Lv ≥5 + 名聲 ≥100【原】）—— 單機化：收攏 25 個 NPC 居民（好感 ≥50 可以遊說；居民用 Spec 09 居民表；隨想簡化：10 個「擁護 NPC」都得，mark【自訂】方便測試）
3. 經費 **20 萬** 兩【原】
4. 定居城池唔可以係新手城（許昌/襄陽/新野【原 許昌襄陽洛陽 → 換新野】）→ v1 要早搬城（加擴地圖做「定居」功能）
5. 「團/起義」指令：名號（唯一）+ 暗號（頭目管理用）→ 成立

- 頭目 + 擁護者自動入會【原】；頭銜/名聲消耗：無（唔扣，只係條件）。
- **S08e 單機化實作**：`ch.homeCity` = 定居城池（`cmd_settle`，要企喺目標城池入面；新手城照定居得，只係唔可以喺度成立）；擁護者 = 居民（好感 ≥50 + Lv ≥5，`cmd_militia_invite`），存快照 `ch.militia.supporters`；成立 = `cmd_militia_found(name, password)`，扣 20 萬、存 `ch.militia = {founded,name,password,city,grade:1,supporters,foundedDay}`。原版「25 人 + 每人名聲 100」→ 單機【自訂】10 人 + 好感 50（居民無名聲）。名號唯一單機冇從驗證 → 只驗非空/長度。
- 成員/階級：一品~八品（帶兵量增量 8000~1000【原】，名號可自訂【原】只限有城池後）；俸祿由頭目設定【原】。
- 評定會議：一月一期、指派 3 種工作（捐獻/監督/商情）、績效 0~900+ → 功績 −30~+100（【原】對照表）→ 功績 = 升階參考。**S08f 實裝**：`ch.militia.eval = {kinds, lastMerit, lastDay, settledPeriod}`；`cmd_eval_assign` 指派（≤3 類，受指派工作加績效 +20）、`cmd_eval_meeting` 結算上期績效 → 功績 + 績效歸 0 + 重新指派、`_eval_daily` 每月初一自動結算（同一期唔重複）；`rules/militia_work.gd merit_delta` 對照表。

## 2. 帶兵量（【原】sy2_9_19 全公式；**S08e 已實裝**）

```
帶兵量 = 7000(基本, 5 級+入會) + 品階帶兵(8000~1000) + 頭銜帶兵(階 n: 1~20→200/階, 21~40→250/階, 41~50→400/階)
例：征東將軍(50) + 一品 = 7000+8000+13000 = 28000（51~60 階固定 28000）
```

- 頭銜帶兵表（200/250/400 分段, 50 階 = 13000）已喺攻略 → `data/titles.json` 每行加 `soldiers` 欄（`tools/gen_titles.py` 從 sy2_9_19 生成）。
- **S08e sim**：`RulesMilitia.max_soldiers`（未入會 / <5 級 = 0；51 階起固定 28000）；`militia_view` read-model 出 `soldiers`。兵種/戰場實際應用 → S10。

## 4. 義勇軍工作（【原】sy2_8_8 22 項）

- 有城池 10 項內政（開墾/商業/畜牧/礦產/防禦/鑄造/監督/商情/治安/防災）+ 軍事（訓練/情報/徵兵）+ 軍備 9 項（軍馬/兵器/軍糧/藥品/捐錢/捐糧/捐礦/捐材/捐藥）；無城池減去 內政 10 項中 6 項（得監督/商情）。
- 工作執行 = 每日（行動力 10 一次）；效果照城池/營地屬性 + 功績（§1 評定）。徵兵：招募士兵（兵營）；軍馬：買軍馬（兵營馬匹）；軍糧：糧秣→軍糧；藥品：藥材→藥品。
- **S08f 實裝**：`data/camp.json works` 22 項（內政 10 / 軍事 3 / 軍備 9）+ `rules/militia_work.gd`（`available` 依 `m.hasCity` 過濾：「無城池」得監督/商情 + 軍事 3 + 軍備 9 = 14；「有城池」22）。`cmd_militia_work` 執行：內政 → 城池 attr +專長 exp、監督 → 營地建設完成度、商情 → `camp.trade` 情報值、訓練 → `camp.train`、徵兵/軍馬/軍糧/藥品/捐錢捐糧捐礦捐材捐藥 → `camp.stores`（受設施上限封頂）；每項加績效。`ch.militia` 加 `camp`/`merit`/`performance`/`eval`/`role`/`hasCity` 欄（舊存檔兼容）。
- 商情收集：提升「商情情報值」（睇其他城商店/武將情報，Spec 02/04 有引用 85/80 門檻【原】）。
- 義勇軍旗幟：美術層，暫緩。
