# 整體設計 v2（2026-09-22 重寫）

一人 + AI 開發嘅**手機單機**遊戲：重製三國演義 Online 普通玩法，將「其他玩家」換成有記憶、有理念嘅 LLM NPC，將「伺服器社會」換成會自己運轉嘅世界模擬。

**完整系統邏輯規格** = 呢份總覽 + `docs/spec/01~11`（各系統詳細設計：公式、數據結構、數值、測試要點）+ `docs/PLAN.md`（實現路線）。「普通玩法_系統摘要.md」係攻略原文摘錄，spec 先係 remake 設計。

## 2. 設計支柱

1. **一人世界，有人味**：NPC 取代玩家，有記憶、性格、理念
2. **世界自己轉**：時辰、四季、天災、市場、NPC 勢力戰爭，你唔玩佢都動
3. **選擇有後果**：善惡、名聲、理念、好感，改變世界回應你
4. **慢熱懷舊**：練功、生產、收集、養馬、登人嘅滿足感；唔加自動化捷徑
5. **手機友善**：一手操作、隨時中斷、短 session 都有進展

## 3. 核心循環

```
短循環(分鐘):  打怪/工作 → 掉落/物資 → 賣/用/捐 → 變強
中循環(小時):  生產/行商 → 賺錢 → 裝備/座騎/技能 → 挑戰更高區域
長循環(日/週): 名聲 → 頭銜 → 義勇軍 → 登用武將 → 參與戰局 → 攻城池
循環外:       任務鏈（新手→官令→歷史→絕招→戰役）、天災應對、養馬養戰騎
```

## 5. 三個新核心邏輯（世界自己轉嘅引擎）

### 5.1 動態市場（已實作 + 擴充）
供需 factor 0.5~2.0；天災/季節/玩家出貨驅動；跨城價差 = 行商利潤（Spec 05 §6 城際貿易）；商店天災停進貨（Spec 05 §6）。

### 5.2 NPC 記憶與傳聞（memory✔，傳聞待做）
目擊事件 → 好感（已實作 8 格 WITNESS_RANGE）；跨城傳聞擴散（Spec 09 §4：延遲 1~3 game 日）→ 影響任務可得/衛兵/登用/價格（善惡）。

### 5.3 武將同伴（登用待做）
general_npc.csv 1261 武將 → generals.json；理念相合 + 屬性 + 將軍令 → 登用 30 日；忠誠模型；寶物 2 格；國戰第四部隊（Spec 09/10）。

## 6. 手機化原則（不變）

橫屏；點地行路/虛擬搖桿；**點怪自動追擊** + 戰鬥/行走切換掣；底部技能列（新手 4 鍵 5 級後 6 鍵【原】）；對話用預設選項優先；任何時侯暫停/自動存；離線推進（世界時鐘快進結算市場/天災，戰鬥唔離線）；按鈕 ≥48dp。

## 10. 風險

- 美術量、數值平衡 > 技術難度（怪物/武將數據導入能大幅減手工）
- 任務量：攻略文本多 → 分批錄入（先新手+義士絕招鍵 3 條+戰役 1 場）
- LLM 成本/漂移（Tier/預算/schema/白名單/離線後備，已定）
- 範圍膨脹：每步可跑可驗證；唔過驗收唔開下一步（見 PLAN）
