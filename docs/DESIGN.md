# 整體設計 (v1, 2026-09-21)

一人 + AI 開發嘅**手機單機**遊戲：重製三國演義 Online 普通玩法，將「其他玩家」換成有記憶、有理念嘅 LLM NPC，將「伺服器社會」換成會自己運轉嘅世界模擬。
玩法規格見 `普通玩法_系統摘要.md`（【原】= 官方攻略；【自訂】= 自己設計）。進度/步驟見 `PLAN.md`。

## 1. 已定決策

| 世界範圍 | 先 **豫州 + 荊州**，3 新手城：**許昌(豫)、襄陽(荊)、新野(荊)**。洛陽/司隸留作擴展 |

## 2. 設計支柱
1. **一人世界，有人味**：NPC 取代玩家，有記憶、性格、理念
2. **世界自己轉**：時辰、四季、天災、市場、戰事，你唔玩佢都動
3. **選擇有後果**：善惡、名聲、理念，改變世界回應你
4. **慢熱懷舊**：練功、生產、收集嘅滿足感；唔加自動化捷徑
5. **手機友善**：一手操作、隨時中斷、短 session 都有進展

## 3. 核心循環
```
短循環(分鐘):  打怪 → 掉落 → 賣/用 → 變強
中循環(小時):  生產/行商 → 賺錢 → 裝備/座騎/技能 → 挑戰更高區域
長循環(日/週): 名聲 → 頭銜 → 義勇軍 → 登用武將 → 參與戰局
```

### 模組關係
```
      天災/季節(C)
          ↓
 物資產量 → 市場價格(D) ← 玩家買賣
          ↓                 ↓
    NPC 生計/心情        金錢 → 裝備(B)
          ↓                 ↓
     民心(G) ←── 名聲(E) ←── 打怪/任務
          ↓                 ↓
   兵源/經費 ────→ 登用武將(F) → 戰局(H)
                        ↑
              理念 + 善惡(E) 決定誰肯跟你
```
**D、E、F 係新玩法核心**，其餘沿用原版。

### 地圖分區：安全區（城）vs 戰鬥區（野外）
【自訂】現時單一 64×64 grid 冇區分「城內」同「城外」，商店/市場/打怪全部擠埋一齊，手感唔好。改用 `data/zones.json` 定義唔重疊嘅矩形區塊，每區有 `safe: bool`：
- **城內（safe）**：客棧/商店/練兵場/私塾/寺廟所在；唔會生怪；戰鬥指令唔生效（`sim.is_safe(x,y)` 擋住 `_think_player` 出手，追過去都唔會打）
- **城外/野區（unsafe）**：怪物 spawn/重生區（`monsters.json` spawns 嘅 `zone` 對應呢度嘅 zone id）；玩家可以自由戰鬥
- **傳送點**（`travel_points`）：城門一對一連結（如 `gate_out`↔`gate_in`），行近其中一個、發 `cmd_travel(id, point_id)` 即時過去對面，唔使成程行；手機 UI 可以做「一鍵出城/返城」掣
- 未來多城（豫州+荊州）可以加更多 zone + travel_points 對，串連唔同城池/野區，唔使一張大地圖

## 5. 三個新核心邏輯

### 5.1 動態市場（D）
- 每城每種物資有供給、需求、庫存；價格 = `items.json` 基準價 × 供需係數（有上下限，防暴走）
- 驅動因素：天災（蝗災→糧升）、季節（冬天藥材/柴升）、戰事（鐵/箭升）、玩家大量出貨（跌價）、NPC 生產者/消費者
- 跨城價差 = 行商利潤；魅力仍影響買賣價【原】
- 先做**無 UI 模擬器**（跑 1000 日睇通脹/崩盤），穩定再接商店

### 5.2 NPC 記憶與傳聞（E）
- 每個 NPC 一張**結構化記憶表**：對玩家嘅好感、發生過嘅事件（幫過/害過/目擊）、理念、近況摘要
- 玩家行為（殺善人、救人、偷竊）→ 有目擊者先入記憶 → 按社交關係**傳聞擴散**（同城快、跨城慢）
- 影響：買賣價（惡值高更貴【原】）、任務可得性、衛兵態度、能否登用
- 善惡數值保留【原】七階與死亡掉落規則；PK/黃人/天譴呢類多人機制改寫成 NPC 反應

### 5.3 武將同伴（F）
- 武將有理念（義理/霸權/權謀/隱遁/治國）、屬性、忠誠、個人目標
- 登用條件 = 理念相合 + 個人屬性【原】+ 好感；忠誠受你行為、待遇、理念一致度影響，可能離隊
- 同伴入隊戰鬥（取代原版練兵場/山洞「組隊」）；第一版 AI 用規則，主要武將對話用 LLM

## 6. NPC 智能架構（LLM）
```
規則層 (每 tick，便宜、確定、可測試)
  需求 / 日程 / 移動 / 交易 / 戰鬥
        │ 有「值得思考」事件時先觸發（被搭話、目擊、重大事件、每日反思）
        ▼
LLM 層 (慢、事件驅動)          ← 經 `brain` 介面，可換模型
  對話 / 動機 / 記憶摘要 / 傳聞措辭
        │ 輸出限定 JSON，動作白名單
        ▼
規則層驗證 → 執行 → 更新記憶表
```
**鐵律**
1. LLM **只揀動作、生成話語，唔直接改數值**。金錢/物品/傷害全由 rules 結算（防套話刷錢）
2. **NPC 分級**：Tier1 主要武將/劇情 NPC → LLM；Tier2 有名居民 → 偶發 LLM + 模板；Tier3 路人/商販 → 純規則+模板
3. 記憶 = 結構化事實 + 定期摘要，唔存全部聊天記錄
4. **成本控制**：每日 token 預算、緩存、批次處理、冷卻時間；超額自動降級
5. **離線也能玩**：`brain` 有規則/模板版後備（無網絡、API 失敗、預算用完都照玩）
6. **可測試**：`brain` 介面有 mock 實作，`npm test` 唔碰網絡；輸出用 schema 驗證，非法輸出丟棄重試
7. **API 金鑰由玩家自填**，只存本機設定，唔寫入存檔、唔打印 log；冇 key 時 NPC 用模板（離線模式）
8. 全部請求經 OpenRouter 單一 `brain` 實作；模型名、每日預算、逾時放設定檔

## 7. 手機化設計
- **橫屏**；虛擬搖桿或點地行路二選一（原版點地行路，先沿用，A* 尋路）
- 右鍵戰鬥游標 → 手機改為：**點怪即自動追擊**；另設「戰鬥/行走」切換掣（保留原版語意）
- 介面：底部 6 鍵(新手 4 鍵)技能列、左上 HP/MP/SP、右上小地圖、背包/任務/地圖抽屜式面板；按鈕最小 ≥ 48dp
- **短 session**：任何時候可暫停/離開、自動存檔；世界時鐘可選「離線推進」（返嚟時簡化結算市場/天災，戰鬥唔離線）
- 對話 UI：NPC 頭像 + 對話框 + 少量選項掣，允許自由輸入但預設選項優先（手機打字慢）
- 效能：AOI/怪物數量控制，粒子/特效節制；LLM 請求全部非同步，永不阻塞畫面
- 螢幕適配：安全區、多解像度；UI 用 Godot Control/anchor，避免固定像素
